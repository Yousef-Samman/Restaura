# Restaura brand

## Logo
A shiny silver serving cloche (the dome a restaurant lifts to present a dish) with a small AI sparkle.

| File | Use |
| --- | --- |
| `assets/restaura-icon.svg`, `assets/restaura-icon-rounded-512.png`, `-224.png` | App icon and README logo: silver cloche on the brand gradient, rounded corners. |
| `assets/restaura-icon-512.png`, `-200.png`, `-100.png` | Square versions for places that crop to a circle. |
| `assets/restaura-mark.svg` | The silver cloche alone, for gradient or dark backgrounds. |
| `assets/restaura-banner.png` | Cover and banner image (1600x700). |

## Colors
Two bright brand colors, used together as a gradient for the most important actions.

| Name | Hex | Use |
| --- | --- | --- |
| Electric indigo | `#5B4CFF` | Primary: buttons, active states, links, menu tiles |
| Coral | `#FF6B4A` | Accent: badges, alerts, highlights, second menu tone |
| Brand gradient | `#5B4CFF → #A35BE6 → #FF6B4A` | Charge and approve buttons, headers, the icon background |
| Ink | `#14102E` | Text and dark agent cards |
| Cloud | `#F7F7FB` | Page background |
| Silver | `#C9CFD8` with white highlights | The cloche only |

## Type
Manrope: ExtraBold (800) for the wordmark and headings, Regular and SemiBold for body text. Fallback: Arial, Helvetica, sans-serif.

## Rules
- The cloche is always silver with its highlights; never recolor it.
- Keep clear space around the mark of at least the height of the cloche knob.
- Use the gradient for one primary action per screen, not for every button.
