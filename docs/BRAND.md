# Restaura brand

## Logo
A flat brass serving cloche (the dome a restaurant lifts to present a dish) with a small AI sparkle.

| File | Use |
| --- | --- |
| `assets/restaura-icon.svg`, `assets/restaura-icon-rounded-512.png`, `-224.png` | App icon and README logo: brass cloche on emerald, rounded corners. |
| `assets/restaura-icon-512.png`, `-200.png`, `-100.png` | Square versions for places that crop to a circle. |
| `assets/restaura-mark.svg` | The cloche alone, for light backgrounds (emerald details). |
| `backend/app/static/logo.svg` | The cloche alone, for emerald or dark backgrounds (cream details). |
| `assets/restaura-banner.png` | Cover and banner image (1600x700). |

## Colors: Emerald & Brass

| Name | Hex | Use |
| --- | --- | --- |
| Emerald | `#0F2E26` | Primary: headers, buttons, text, the icon background |
| Brass | `#C8A04A` | Accent: the cloche, active states, highlights, second chart series |
| Cream | `#F5EFE3` | Page background, text on emerald |
| Warm gray | `#5F6B60` | Secondary text |

## Type
Playfair Display Bold for the wordmark. Manrope for the app: ExtraBold (800) for headings, Regular and SemiBold for body text. Fallback: Arial, Helvetica, sans-serif.

## Rules
- The cloche is always flat brass; its details are cream on dark backgrounds and emerald on light ones.
- Keep clear space around the mark of at least the height of the cloche knob.
- Use brass sparingly: one highlight per area, not every button.
