# Restaura brand

## Logo
A serving cloche (the dome a restaurant lifts to present a dish) with a small AI sparkle.

| File | Use |
| --- | --- |
| `assets/restaura-icon.svg`, `assets/restaura-icon-512.png`, `-200.png`, `-100.png` | App icon, avatars, favicon. Full square, so it survives circular crops. |
| `assets/restaura-mark-dark-bg.svg` | Mark alone on slate or other dark backgrounds. |
| `assets/restaura-mark-light-bg.svg` | Mark alone on cloud or white backgrounds. |
| `assets/restaura-banner.png` | Cover and banner image (1600x700). |

## Colors
| Name | Hex | Use |
| --- | --- | --- |
| Slate | `#1F2937` | Main dark, text on light, app chrome |
| Silver | `#B7BFCC` | The cloche, accents, secondary elements |
| Cloud | `#F8FAFC` | Main light background, text on dark |

Supporting neutrals used in the banner: `#E2E8F0` (secondary text on dark) and `#CBD5E1` (borders on light).

## Type
Manrope, ExtraBold (800) for the wordmark and headings, Regular and SemiBold for body text. Fallback: Arial, Helvetica, sans-serif.

## Rules
- Keep clear space around the mark of at least the height of the cloche knob.
- Do not place the silver mark on a light background; use the light-background mark.
- Do not recolor the mark outside this palette.
