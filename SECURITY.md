# Security

Restaura is a hackathon demo. Please report a security problem privately through
GitHub's "Report a vulnerability" button (Security tab) instead of opening a public issue.

Keys and passwords never go in the repository. Use environment variables (see `.env.example`).
The demo logins are for demos only; set `MANAGER_PASSWORD`, `CASHIER_PASSWORD` and `DEMO_MODE=0` for a real store.
